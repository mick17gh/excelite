# Excelite POS Design System

## Brand
- **Name:** Excelite POS
- **Logo:** `/public/excelite_logo.png`
- **Tagline:** POS software built for small businesses

## Colors
| Token | Hex | Usage |
|-------|-----|-------|
| Charcoal | `#222831` | Headings, primary text |
| Green | `#22C55E` | CTAs, active nav, success |
| Green dark | `#16A34A` | Hover states, gradients |
| Background | `#FFFFFF` | Page background |
| Muted | `#F4F4F5` | Cards, secondary surfaces |
| Border | `#E4E4E7` | Dividers |

## Typography
- **Headings:** Poppins (`--font-poppins`)
- **Body:** Open Sans (`--font-open-sans`)

## UI Principles
- Flat white sidebar (no blue gradients)
- Green left-border active nav items
- Minimal cards with light borders
- Prominent "Open POS" CTAs
- Mobile bottom nav on small screens

## Anti-patterns
- ServStack blue/purple gradients
- Enterprise feature marketing (KDS, CRM, AI tiers)
- Heavy glassmorphism on data tables
